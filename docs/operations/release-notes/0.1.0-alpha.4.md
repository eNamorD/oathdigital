# Oath Digital 0.1.0-alpha.4
2026-10-26

Hello all, it's been a while! Here is the third release of the alpha.
This one took a month, but a lot has been added in that time. Almost every
denizen is in now, there is an undo feature, a consent system, and the
UI has been streamlined some too!

## What's new

- Implemented most of the remaining cards: we are now at 230 out of 255
  denizens, and 37 out of 48 relics.
- Undo and Redo. Take back your last move with Undo, and put it back with
  Redo. The game log groups the undone moves together.
- UI options on the board. Most decisions which require selecting a site,
  card, pawn, etc. can now be selected on the map instead of through a button.
- Invalid options will be grayed out, and hovering over them will tell you the
  reason why.
- Consent system. When a toll, the Narrow Pass, the Hall of Ministers or
  a similar card blocks you, you can ask its ruler to let you through.
  Rulers can also set their answers ahead of time by clicking on the relevant power.
- Some touchups to the game log. For instance, each major action is grouped under a colored band.

## Not in the game yet

- The Chronicle, Empire and anything past a single all-Exile game.
- A Chronicle import/export feature, to make the app compatible with the TTS mod.
- 25 denizens, 11 relics and 24 edifices. Most of these rely on the Chronicle
  or Empire features.

## Saved games

This is an alpha: **games saved by 0.1.0-alpha.3 or earlier won't load in
this release**, and games saved by this release may not load in the next one.
No release promises to open another release's saved games yet.

The Start file keeps its games in the same folder for every version. To start
fresh, stop Oath Digital and move your save folder somewhere else:

- **macOS**: `~/Library/Application Support/OathDigital/data`
- **Windows**: `%LOCALAPPDATA%\OathDigital\data`
- **Linux**: `~/.local/share/oathdigital/data`

Moving the folder back and running the old release gets your old games back.

## Getting started

Download the archive below for your computer, extract it, then:

- **macOS**: double-click `Start Oath Digital.command`
- **Windows**: double-click `Start Oath Digital.bat`
- **Linux**: run `./start-oathdigital.sh`

For the full walkthrough (dealing with security prompts, creating and sharing your first game's seat links), see
[the quick start guide](https://github.com/eNamorD/oathdigital/blob/v0.1.0-alpha.4/docs/operations/quick-start.md).

Each download below is checked against `SHA256SUMS`, also attached, if you'd
like to verify your copy.

## Known caveats

- Each player seat needs a separate browser profile: opening a
  second seat's link in the same browser silently kicks you out of the
  first. Use a different browser, or a separate
  profile/private window, for each seat you open yourself.
- Asking permission is brand new and has only been checked by automated
  tests so far. Please report anything odd.
