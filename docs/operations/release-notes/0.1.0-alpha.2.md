# Oath Digital 0.1.0-alpha.2

_2026-09-24_

Hello fellow Oath fans! I'd like to present to you: the first alpha release of Oath Digital!

## Features

- All-exile game using the New Foundations first-game setup
- 30+ denizens, 6 edifices and 3 relics implemented

## Not in the game

- The rest of the denizens, edifices and relics
- A consent system. (Right now, implemented powers are always enforced)
- Foundations and legacies
- All chronicle steps
- Empire-related rules
- Chronicle Import/Export (compatible with TTS)
- Art assets (so that BGS won't send ninja assassins to my house)

## Getting started

Download the archive below for your computer, extract it, then:

- **macOS**: double-click `Start Oath Digital.command`
- **Windows**: double-click `Start Oath Digital.bat`
- **Linux**: run `./start-oathdigital.sh`

For the full walkthrough (dealing with security prompts, creating and sharing your first game's seat links), see
[the quick start guide](https://github.com/eNamorD/oathdigital/blob/v0.1.0-alpha.2/docs/operations/quick-start.md).

Each download below is checked against `SHA256SUMS`, also attached, if you'd
like to verify your copy.

## Known caveats

- Each player seat needs a separate browser profile: opening a
  second seat's link in the same browser silently kicks you out of the
  first. Use a different browser, or a separate
  profile/private window, for each seat you open yourself.
