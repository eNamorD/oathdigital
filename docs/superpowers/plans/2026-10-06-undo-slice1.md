# Undo, Slice 1 (Engine, Storage and Server Log) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player can take back their latest command, through the service and the wire, back to the latest barrier. The projection offers the Undo to the right player, and the Game Log marks what was taken back.

**Architecture:**

- **Batch boundaries.** Every accepted command except Begin appends `CommandAccepted(actor)` before its own events. The rules engine never builds it.
- **One forward fold.** A new application-layer `JournalFold` replaces the service's use of `EventReplayEngine`.
  - It replays every event in order and keeps a live stack of the batches since the latest barrier.
  - A `StepTakenBack(from, until, by)` marker rewinds the state to the top batch's state before and pops the batch.
  - `load`, `history` and `handle` all read the same `FoldedJournal`.
- **Barriers.** `UndoBarrier.blocks` decides from a closed batch's events and the states around it. A batch is a barrier when it holds a hidden outcome, holds a legacy reveal, hands the turn over, sets a result, or begins at `NoGame`.
- **Undo command.** `GameCommand.Undo(actor)` bypasses the walker-pending gate. It appends one marker and returns the top batch's state before.
- **Offer.** `LoadedGame` and `GameAccepted` carry `undo: Option[UndoStep]` and `logRevision: Option[Long]`. The projector turns those into `GameProjection.undo` (for the issuer only) and `GameProjection.logRevision`.
- **Log.**
  - A marker closes a segment.
  - The formatter's `Run` rewinds on a marker.
  - Every entry posted by a voided event carries a `takenBack` group: an id plus the header spans "p1 took back the following moves:".
- **Known cost.** The undo note formats the log up to the offered batch's end on every `load` and every accepted command. That doubles the formatting the log route already does. It is accepted for the alpha; formatting only from the batch's run start is the later optimization.

**Tech Stack:** Scala 3 on the JVM and Scala.js, munit, ujson, built through `./sbtw`. No frontend UI change; the shared codecs gain fields that the frontend decodes.

**Spec:** `docs/superpowers/specs/2026-10-06-undo-design.md`. Read the whole spec before starting. Slice 1 is its "Slices" item 1. Redo (`StepRestored`, the redo stack) is slice 3 and is **not** in this plan.

```scala
package oathdigital.serialization

import oathdigital.model._
import oathdigital.model.OathEvent.{CommandAccepted, StepTakenBack}

/** Undo's journal facts (undo design, "Storage"). */
private[serialization] trait UndoEventCodec { this: GameEventJsonSupport =>
  import GameEventWire._

  protected final val undoDiscriminator: PartialFunction[OathEvent, String] =
      case _: CommandAccepted => CommandAcceptedType
      case _: StepTakenBack => StepTakenBackType

  protected final val undoEncoder: PartialFunction[OathEvent, ujson.Value] =
      case CommandAccepted(by) => ujson.Obj("by" -> by.value)
      case StepTakenBack(from, until, by) => ujson.Obj(
        "from" -> ujson.Num(from.toDouble),
        "until" -> ujson.Num(until.toDouble),
        "by" -> by.value)

  protected final def undoDecode(eventType: String, payload: ujson.Value,
      path: String): Option[Either[WireError, OathEvent]] =
    val decoder: PartialFunction[String, Either[WireError, OathEvent]] =
        case CommandAcceptedType =>
          Right(CommandAccepted(PlayerId(payload("by").str)))
        case StepTakenBackType => for
          from <- safeIntegerField(payload.obj, "from", path)
          until <- safeIntegerField(payload.obj, "until", path)
        yield StepTakenBack(from, until, PlayerId(payload("by").str))
    decoder.lift(eventType)
}
```

```scala
package oathdigital.application

import oathdigital.gameplay.walker.{HiddenOutcomes, RollPayload,
  WalkerStepRecorded}
import oathdigital.model._
import oathdigital.model.OathEvent.{OwnedRelicRevealed, SiteRelicsPeeked}

/** Whether a closed command batch is a barrier that undo never takes back
  * (undo design, "Barrier detection"). It reads only the batch's events and
  * the states around it, so the rules engine stays unaware of undo. */
private[application] object UndoBarrier:
  def blocks(events: Vector[OathEvent], before: OathState, after: OathState)
      : Boolean =
    (before, after) match
      case (OathState.Ready(start), OathState.Ready(end)) =>
        events.exists(reveals) ||
          start.game.current.turn.activePlayer !=
            end.game.current.turn.activePlayer ||
          end.game.current.result.nonEmpty
      case _ => true

  private def reveals(event: OathEvent): Boolean = event match
    case step: WalkerStepRecorded =>
      step.payload.isInstanceOf[RollPayload] || step.ops.exists(hidden)
    case _: SiteRelicsPeeked | _: OwnedRelicRevealed => true
    case _ => false

  /** A composite operation hides when any operation inside it does. */
  private def hidden(operation: Operation): Boolean =
    HiddenOutcomes.hides(operation) || operation.children.exists(hidden)
```

If `Operation` names its sub-operations something other than `children`, use that name (`CoreOperations.scala:409` shows `Reveal` overriding `children`).

```scala
package oathdigital.application

import oathdigital.model._
import oathdigital.serialization.GameEventWire

/** Journal surgery for undo tests: reading a stream's events, and writing
  * streams the service itself would never write. */
object UndoJournals:
  def events(repository: EventStreamRepository, gameId: String)
      (using munit.Location): Vector[OathEvent] =
    repository.load(gameId).toOption.flatten.toVector
      .flatMap(_.records).map(record =>
        GameEventWire.decode(record).fold(
          error => munit.Assertions.fail(s"undecodable: $error"), _.event))

  /** `gameId`'s journal as written before command batches were recorded:
    * every `CommandAccepted` dropped and the rest renumbered. */
  def withoutBatchOpenings(repository: EventStreamRepository, gameId: String)
      (using munit.Location): InMemoryEventStreamRepository =
    rewritten(events(repository, gameId)
      .filterNot(_.isInstanceOf[OathEvent.CommandAccepted]), gameId)

  /** A fresh repository holding exactly `events` as `gameId`. */
  def rewritten(events: Vector[OathEvent], gameId: String)
      (using munit.Location): InMemoryEventStreamRepository =
    val copy = new InMemoryEventStreamRepository
    val records = events.zipWithIndex.map { case (event, index) =>
```

```scala
package oathdigital.application

import oathdigital.engine.{EventReplayFailure, RecordedEvent, ReplayStep}
import oathdigital.model._
import oathdigital.model.OathEvent.{CommandAccepted, StepTakenBack}

/** One command's batch (undo design, "Terms"): the events in `[from,
  * until)`, opened by `CommandAccepted(issuer)`, with the states around it. */
final case class CommandBatch(from: Long, until: Long, issuer: PlayerId,
    before: OathState, after: OathState)

/** The folded journal (undo design, "Replay: one forward fold"): the current
  * state, one step per event (markers included), and the live stack, the
  * batches since the latest barrier, latest first. */
final case class FoldedJournal(state: OathState,
    steps: Vector[ReplayStep[OathState, OathEvent]],
    live: List[CommandBatch]):
  def undoable: Option[CommandBatch] = live.headOption

  /** The sequence of the latest taken-back marker: a client whose log
    * predates it must refetch the whole log (undo design, "Game Log"). */
  def logRevision: Option[Long] = steps.reverseIterator.collectFirst {
    case ReplayStep(RecordedEvent(index, _: StepTakenBack), _, _) => index }

  private[application] def recorded(record: RecordedEvent[OathEvent],
      after: OathState): FoldedJournal =
    copy(state = after, steps = steps :+ ReplayStep(record, state, after))

/** Replays a journal forward, every event in order, voided or not. A
  * marker rewinds to a state the fold already holds, so no event is evolved
  * twice and no snapshot is stored. */
private[application] final class JournalFold(
    evolve: (OathState, OathEvent) => Either[OathViolation, OathState]):
  private type Result[A] = Either[EventReplayFailure[OathViolation], A]

  def fold(initial: OathState, records: Iterable[RecordedEvent[OathEvent]])
      : Result[FoldedJournal] =
    extend(FoldedJournal(initial, Vector.empty, Nil), records)

  /** `journal` continued by `records`, which begin at its end. A batch never
    * spans two appends, so the batch `records` leave open closes at their
    * end. */
  def extend(journal: FoldedJournal,
      records: Iterable[RecordedEvent[OathEvent]]): Result[FoldedJournal] =
    records.foldLeft[Result[Progress]](Right(Progress(journal, None))) {
      case (Right(progress), record) => progress.next(record)
      case (failure, _) => failure
    }.map(progress => progress.closedAt(progress.journal.steps.lastOption
      .fold(0L)(_.event.index + 1)))

  private final case class Open(from: Long, issuer: PlayerId,
      before: OathState)

  private final case class Progress(journal: FoldedJournal,
      open: Option[Open]):
    /** The journal with the open batch, if any, closed before `until`: a
      * barrier empties the live stack, anything else is pushed onto it. */
    def closedAt(until: Long): FoldedJournal = open.fold(journal) { batch =>
      val events = journal.steps.slice(batch.from.toInt, until.toInt)
        .map(_.event.event)
      val closed = CommandBatch(batch.from, until, batch.issuer,
        batch.before, journal.state)
      journal.copy(live =
        if UndoBarrier.blocks(events, batch.before, journal.state) then Nil
        else closed :: journal.live)
    }

    def next(record: RecordedEvent[OathEvent]): Result[Progress] =
      record.event match
        case CommandAccepted(by) =>
          val settled = closedAt(record.index)
          Right(Progress(settled.recorded(record, settled.state),
            Some(Open(record.index, by, settled.state))))
        case StepTakenBack(from, until, by) =>
          val settled = closedAt(record.index)
          settled.live match
            case top :: rest if top.from == from && top.until == until &&
                top.issuer == by =>
              Right(Progress(settled.recorded(record, top.before)
                .copy(live = rest), None))
            case _ => Left(EventReplayFailure(record.index,
              OathViolation.InvalidEventOrder(s"taken-back [$from, $until) " +
                s"by ${by.value} is not the latest live batch")))
        case event => evolve(journal.state, event).left
          .map(EventReplayFailure(record.index, _))
          .map(after => copy(journal = journal.recorded(record, after)))
```

`steps.slice(from, until)` relies on step positions equalling journal sequences, which holds because every stream starts at sequence 0 (`decodeRecords` enforces it).

```scala
package oathdigital.application.gamelog

import oathdigital.model._
import LogSpan.Text

/** Marks every entry posted by a voided event with its taken-back group
  * (undo design, "Game Log"): one group per contiguous run of voided
  * entries, headed by the players whose undos made it. */
private[gamelog] final class TakenBackGroups(words: LogWords):
  def mark(journal: LogJournal, entries: Vector[LogEntry]): Vector[LogEntry] =
    val voided = (0 until journal.size).flatMap(at => journal.event(at) match
      case OathEvent.StepTakenBack(from, until, by) => Some((from, until, by))
      case _ => None).toVector
    def issuer(entry: LogEntry): Option[PlayerId] = voided.collectFirst {
      case (from, until, by) if entry.sequence >= from &&
          entry.sequence < until => by }
    val runs = entries.foldLeft(Vector.empty[Vector[(LogEntry, Option[PlayerId])]]) {
      (done, entry) =>
        val tagged = entry -> issuer(entry)
        done.lastOption match
          case Some(run) if run.last._2.nonEmpty == tagged._2.nonEmpty =>
            done.init :+ (run :+ tagged)
          case _ => done :+ Vector(tagged)
    }
    runs.flatMap { run =>
      if run.head._2.isEmpty then run.map(_._1)
      else
        val group = LogTakenBack(run.head._1.sequence,
          header(run.flatMap(_._2).distinct))
        run.map((entry, _) => entry.copy(takenBack = Some(group)))
    }

  private def header(players: Vector[PlayerId]): Vector[LogSpan] =
    val names = players.map(words.player)
    val listed = names match
      case Vector(only) => Vector(only)
      case _ => names.init.zipWithIndex.flatMap { (name, index) =>
        if index == 0 then Vector(name) else Vector(Text(", "), name)
      } ++ Vector(Text(" and "), names.last)
    listed :+ Text(" took back the following moves:")
```
