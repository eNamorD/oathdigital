# Undo, Slice 2 (Frontend) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player offered an Undo sees the control and its hover note in the Actions pane. Every reader sees taken-back moves as collapsed, struck-through groups in the Game Log, and the log refetches itself whenever an undo changes lines it already shows.

**Architecture:**

- **Undo control.** A new `UndoControl` renders one Action-face "Undo" button when `GameProjection.undo` is present. Its `title` is the offer's note, and pressing it submits `GameIntent.Undo`. `ActionDecisionRenderer.actionsPanel` places it directly under the status line. The server decides who sees the offer, so the client shows the button whatever the phase, and also while the walker waits on another player.
- **Taken-back groups.** `GameLogPane` renders each contiguous run of entries with the same `takenBack.group` as one `li.log-taken-back`:
  - a toggle button showing the group's header spans, with `aria-expanded`;
  - a nested `ol.log-taken-back-lines`, hidden by default, holding the run's ordinary entry items with their band classes.
  - Each pane remembers which groups the reader opened, so a redraw keeps them open.
  - Bands never join across a group's edge.
- **Append or redraw.** An append now requires the new entries to extend the shown ones exactly (`entries.startsWith(shown)`), and no new entry may carry `takenBack`. Anything else redraws. A redraw within the same session keeps the reader's place: a reader at the end stays at the end, and anyone else keeps their `scrollTop`. Only the first draw of a session still jumps to the divider.
- **Log refetch.** `TableSession` remembers the `logRevision` its log was fetched under. When a displayed projection carries a different one, the session:
  - drops any request in flight (epoch bump);
  - asks for the log from sequence 0;
  - replaces the log with the answer.
  - The old lines stay on show until the new page lands, so the log never flashes empty. This is the spec's `resetLog()`-and-refetch without the empty frame.

```scala
package oathdigital.frontend

import oathdigital.protocol.{GameIntent => GameCommand}
import org.scalajs.dom
import ServerUiSupport._

/** The Undo control (undo design, "Controls"). The server offers the step
  * only to the player who may take it back, so the control shows whenever
  * the projection carries an offer: in any phase, and while the walker waits
  * on another player. The label is always "Undo"; the hover note names what
  * the press would take back. There is no keyboard shortcut. */
private[frontend] object UndoControl:
  def render(value: GameProjection, canControl: Boolean,
      submit: GameCommand => Unit): Option[dom.html.Button] =
    value.undo.map { offer =>
      val control = button("Undo", "undo-action")
      control.title = offer.note
      control.disabled = !canControl
      control.onclick = _ => submit(GameCommand.Undo)
      control
    }
```

   ```scala
     /** `since` is the stored marker. It places the divider only when the list
       * is drawn in full, so appends never move it. An undo changes lines
       * already shown, and a taken-back line is drawn inside its group, so
       * only new live lines at the end append; anything else redraws. */
     def show(sessionKey: String, entries: Vector[LogEntryWire],
         colors: Map[String, String], since: Option[Long] = None): Unit =
       val sameSession = key.contains(sessionKey)
       if !sameSession then expanded = Set.empty
       val appending = sameSession && shown.nonEmpty &&
         entries.startsWith(shown) &&
         entries.drop(shown.size).forall(_.takenBack.isEmpty)
       if appending then
         if entries.size > shown.size then
           val following = atEnd
           // A line that continues the last entry's band moves the band's
           // end down to itself; anything else starts a band of its own.
           entries.drop(shown.size).foldLeft(shown.last) { (previous, entry) =>
             val continues = GameLogPane.joined(previous, entry)
             if continues then Option(list.lastElementChild)
               .foreach(_.classList.remove("log-band-end"))
             list.appendChild(item(entry, colors, start = !continues, end = true))
             entry
           }
           if following then toEnd() else chip.removeAttribute("hidden")
       else redraw(entries, colors, since,
         keepPlace = sameSession && shown.nonEmpty)
       key = Some(sessionKey)
       shown = entries
   ```

4. Replace `redraw` with:

   ```scala
     /** `keepPlace` is a redraw of a list already on show, after an undo: a
       * reader at the end stays there and anyone else keeps their scroll.
       * Only a session's first draw goes to the divider. */
     private def redraw(entries: Vector[LogEntryWire], colors: Map[String, String],
         since: Option[Long], keepPlace: Boolean): Unit =
       val following = atEnd
       val top = content.scrollTop
       while list.firstChild != null do list.removeChild(list.firstChild)
       chip.setAttribute("hidden", "")
       if entries.isEmpty then list.appendChild(headline(GameLogPane.placeholder, "round"))
       // A divider never splits a group: it stands before the group's first
       // line instead.
       val divideAt = since.map(marker => entries.indexWhere(_.sequence > marker))
         .filter(_ >= 0).map(at => entries(at).takenBack.fold(at)(group =>
           entries.indexWhere(_.takenBack.exists(_.group == group.group))))
       // The divider ends the band above it and starts the band below it.
       entries.zipWithIndex.foldLeft(Option.empty[(Long, dom.Element)]) {
         case (open, (entry, index)) =>
           val divided = divideAt.contains(index)
           if divided then list.appendChild(GameLogPane.divider)
           val start = divided ||
             !entries.lift(index - 1).exists(GameLogPane.joined(_, entry))
           val end = divideAt.contains(index + 1) ||
             !entries.lift(index + 1).exists(GameLogPane.joined(entry, _))
           val node = item(entry, colors, start, end)
           entry.takenBack match
             case None =>
               list.appendChild(node)
               None
             case Some(taken) =>
               val lines = open.filter(_._1 == taken.group).map(_._2)
                 .getOrElse(group(taken, colors))
               lines.appendChild(node)
               Some(taken.group -> lines)
       }
       if keepPlace then
         if following then toEnd() else content.scrollTop = top
       else divideAt.fold(toEnd())(_ => reveal(list.querySelector(".log-divider")))

     /** A taken-back group (undo design, "Game Log"): a toggle naming who took
       * the moves back, over the lines, collapsed unless the reader opened
       * it. Appends the group to the list and returns the list its lines go
       * in. */
     private def group(taken: LogTakenBackWire, colors: Map[String, String])
         : dom.Element =
       val node = element("li", "log-taken-back")
       val toggle = button("", "log-taken-back-toggle")
       taken.header.foreach(span =>
         toggle.appendChild(GameLogPane.spanNode(span, colors)))
       val lines = element("ol", "log-taken-back-lines")
       def open(value: Boolean): Unit =
         toggle.setAttribute("aria-expanded", value.toString)
         if value then lines.removeAttribute("hidden")
         else lines.setAttribute("hidden", "")
       open(expanded.contains(taken.group))
   ```
