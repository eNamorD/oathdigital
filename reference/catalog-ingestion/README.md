# Catalog transcription sources

These files are the transcription evidence the runtime catalog was built
from. The generator (`build_runtime_catalog.py`) and its reviewed mirrors
were retired in the card classes phase: card data is now Scala, see
`docs/catalog/reference/README.md`. Nothing here is loaded or regenerated.

- `base-denizen-transcriptions.json` contains the retained base-game denizen
  IDs and text. It was generated by `extract_base_card_data.py` from the
  Buried Giant Oath card database and the MIT-licensed LeCodex Oath rules
  implementation, then reviewed and pruned for the runtime corpus.
- `new-foundations-denizen-transcriptions.json` contains visually reviewed
  transcriptions of the revised and new denizens in the supplied New
  Foundations print sheets. The public New Foundations TTS card images and
  ID table were used as a second visual reference.
- `base-denizen-transcriptions.json` and
  `new-foundations-denizen-transcriptions.json` preserve the earlier
  transcription provenance. Reviewed corrections were promoted into the
  runtime catalog, so these files may still carry stale handler keys or rules
  text.
- `relic-transcriptions.json` contains visually reviewed printed IDs, relic
  values, defenses, and rules from the supplied relic print sheets.
- `legacy-transcriptions.json` contains visually reviewed printed IDs and
  rules from the supplied legacy print sheets.
- `edifice-rule-overrides.json` corrects symbol-bearing or otherwise
  incomplete edifice OCR against the supplied print sheets and individual TTS
  card images.

Resource icons are transcribed as `[favor]`, `[favor-burnt]`, `[secret]`, and
`[secret-burnt]`. Other gameplay icons use documented bracket tokens. Printed
bold and italic text is preserved as Markdown.

Known archived OCR naming errors are resolved in reviewed inputs and generator
mappings, while the source archive remains unchanged. Examples include `Land
Garden` → `Land Warden`, `King of Devotion` → `Ring of Devotion`, and
`Keeping Banner` → `Weeping Banner`.
